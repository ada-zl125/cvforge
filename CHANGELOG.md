# Changelog

## [1.2.1] 2026.07.26

1. Migrated Agent Mode to LangChain Deep Agents and LangGraph.
2. Added reusable agent runtimes, streamed responses, and parallel tool execution.
3. Improved tool call and reasoning message compatibility across providers.
4. Added provider detection and thinking controls for popular model services.
5. Added context usage display and Markdown reasoning output.
6. Preserved uploaded reference filenames and improved browser runtime stability.
7. Improved chat message visibility, review accuracy, and undo safety.
8. Simplified prompts and agent orchestration for clearer and more reliable behavior.

## [1.2.0] 2026.07.01

1. Added Agent Mode for resumes, academic CVs, and cover letters.
2. Added streamed document editing, clarification, review, and undo.
3. Added project instructions and local PDF, Markdown, and text references.
4. Improved context retrieval, PDF parsing, and upload feedback.
5. Improved Chinese documents, examples, punctuation, and interface coverage.
6. Improved editor layout, pagination, responsive preview, and export reliability.
7. Improved browser session handling while preserving LLM configuration.
8. Refactored shared editor and agent components for clearer maintenance.
9. Updated project documentation for this release.

## [1.1.1] 2026.05.03

1. Fixed interface display issues.
2. Added responsive layouts for different screen sizes.
3. Added collapsible panels and resizable editor layouts.

## [1.0.1] 2026.04.26

1. Removed resume address fields that only apply to academic CVs.
2. Updated the application icon.

## [1.0.0] 2026.04.26

1. Released resume, academic CV, and cover letter editors.
2. Added live A4 previews.
3. Added PDF, PNG, and JSON export.
4. Added JSON import.
5. Added English and Chinese interface support.
6. Added private client side storage without user accounts.
